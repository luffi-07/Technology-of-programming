# Лабораторная работа №8 — Вариант 4. Счётчик посещений

**Дисциплина:** Языки и технология программирования
**Хранилище:** localStorage (lab8_visits) и sessionStorage (lab8_visits_session)
**ФИО / группа / вариант:** _заполнить_

## Цель
Сохранение и восстановление пользовательских данных через JSON.stringify() / JSON.parse() и Web Storage.

## Структура данных (пример JSON)
```json
{"count":5,"last":"2026-10-22T10:00:00.000Z"}
```

## События интерфейса
загрузка страницы (увеличение счётчика), click (Сбросить)

## Запуск
Открыть папку в VS Code → Live Server (не через file://). Проверка данных: DevTools → Application → Storage.

## Тестирование (заполнить фактический результат и статус)
| Тест | Действие | Ожидаемый результат | Фактический результат / статус |
|---|---|---|---|
| T1 | Первый запуск | Пустой интерфейс без ошибок | |
| T2 | Добавление / изменение данных | Данные появились и сохранены в Storage | |
| T3 | Обновление страницы | Данные восстановились | |
| T4 | Удаление / сброс | Данные исчезли из интерфейса и хранилища | |
| T5 | Пустой или неверный ввод | Некорректная запись не создается | |
| T6 | Вручную испортить JSON в Storage | Приложение не падает, показывает пустое состояние | |
