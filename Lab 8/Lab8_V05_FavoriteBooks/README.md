# Лабораторная работа №8 — Вариант 5. Избранные книги

**Дисциплина:** Языки и технология программирования
**Хранилище:** localStorage, ключ lab8_books
**ФИО / группа / вариант:** _заполнить_

## Цель
Сохранение и восстановление пользовательских данных через JSON.stringify() / JSON.parse() и Web Storage.

## Структура данных (пример JSON)
```json
[{"id":1,"title":"Абай жолы","author":"М. Ауэзов"}]
```

## События интерфейса
submit формы, click (Удалить)

## Запуск
Открыть папку в VS Code → Live Server (не через file://). Проверка данных: DevTools → Application → Storage.

## Тестирование (заполнить фактический результат и статус)
| Тест | Действие | Ожидаемый результат | Фактический результат / статус |
