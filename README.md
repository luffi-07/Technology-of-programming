# Мини-проект: Система «Учет личных расходов»

## 1. Название и цель проекта, описание проблемы и целевой аудитории
* **Название проекта:** Personal Expense Tracker (Учет личных расходов).
* **Цель проекта:** Разработка удобного программного инструмента для фиксации доходов и расходов пользователя, контроля текущего баланса, анализа категорий трат и формирования финансовой отчетности.
* **Описание проблемы:** Большинство людей сталкиваются с трудностями при контроле спонтанных трат, что приводит к нехватке средств. Отсутствие наглядной статистики и анализа бюджета мешает грамотно распределять финансы.
* **Целевая аудитория:** Студенты, молодые специалисты и пользователи, желающие сформировать привычку финансового планирования.

## 2. Анализ предметной области и аналогов
* **Предметная область:** Финансы, личное бюджетное планирование.
* **Обзор аналогов:** 
  1. *CoinKeeper* — популярное приложение с визуальным распределением бюджета, но с избыточным функционалом и платными подписками.
  2. *Google Таблицы* — гибкий инструмент, требующий ручного создания формул и неудобный для быстрого ввода данных.
  3. *Разрабатываемый проект* — легкое решение с интуитивным интерфейсом и базовым набором отчетов.
* **Источники / Ссылки на аналоги:** [CoinKeeper](https://coinkeeper.me/), [Google Таблицы](https://sheets.google.com).

## 3. Функциональные возможности и ограничения
* **Функциональные возможности:**
  1. Добавление новых операций (доход или расход) с указанием суммы, категории, даты и комментария.
  2. Просмотр текущего общего баланса (доходы минус расходы).
  3. Фильтрация и просмотр отчетов по категориям трат.
  4. Валидация вводимых данных (защита от некорректного ввода).
* **Ограничения:** Локальное хранение данных и поддержка одной валюты.
