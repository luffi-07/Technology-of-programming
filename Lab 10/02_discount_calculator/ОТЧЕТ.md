# Калькулятор скидки

**Лабораторная работа №10 — ES-модули**

## Цель
Научиться разделять JavaScript-приложение на независимые модули, использовать `import` и `export`, отделять логику от интерфейса и проверять работу приложения.

## Постановка задачи
Модуль pricing.js рассчитывает размер скидки и итоговую стоимость; main.js читает форму и показывает результат.

## Структура проекта
- `index.html` — разметка страницы;
- `styles/style.css` — оформление;
- `src/main.js` — точка входа и обработчики событий;
- `src/modules/` — отдельные модули бизнес-логики, данных и интерфейса.

## Проверка работы
| № | Сценарий | Ожидаемый результат |
|---|---|---|
| 1 | Цена 1000, скидка 10% | Скидка 100 ₸, итог 900 ₸ |
| 2 | Цена 2500, скидка 0% | Итог 2500 ₸ |
| 3 | Цена 2000, скидка 100% | Итог 0 ₸ |
| 4 | Пустая цена | Сообщение о заполнении |
| 5 | Скидка 120% | Сообщение об ошибке диапазона |

## Запуск
Откройте терминал в папке проекта и выполните:

```bash
python -m http.server 8000
```

Затем откройте `http://localhost:8000` в браузере. ES-модули следует запускать через локальный HTTP-сервер, а не через `file://`.

## Вывод
В ходе работы приложение разделено на отдельные ES-модули. Функции экспортируются из файлов и импортируются в `main.js`. Обработка пользовательских событий и проверка некорректных данных помогают сделать приложение удобным и устойчивым к ошибкам.
