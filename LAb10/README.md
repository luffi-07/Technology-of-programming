# Лабораторная работа №10 — Вариант 12: «Калькулятор бюджета»

Основы модульности и структуры проекта: разделение кода на файлы, использование ES-модулей.

## Как запустить в PyCharm

1. Распакуйте архив и откройте папку `Lab10_ESModules` через **File → Open**.
2. Откройте `run_server.py` → правый клик → **Run 'run_server'**.
3. Браузер откроется на `http://localhost:8000` (или откройте этот адрес вручную).

Альтернатива: в терминале PyCharm выполните `python -m http.server 8000`.
Открывать `index.html` двойным щелчком (file://) нельзя — ES-модули не загрузятся.

Проверка логики без браузера: `node tests/test.mjs` (нужен Node.js).

## Структура проекта

```
Lab10_ESModules/
├── index.html
├── run_server.py
├── styles/style.css
├── src/
│   ├── main.js              ← точка входа, события, связывает модули
│   └── modules/
│       ├── budget.js        ← бизнес-логика: доходы/расходы, валидация, итоги
│       ├── format.js        ← форматирование сумм, дат, месяцев
│       ├── ui.js            ← работа с DOM: баланс, диаграмма, список
│       └── storage.js       ← (творческое задание) сохранение в localStorage
└── tests/test.mjs           ← автоматические проверки логики
```

## Схема зависимостей

```
index.html
   └── main.js
        ├── budget.js   (без зависимостей)
        ├── format.js   (без зависимостей)
        ├── storage.js  (без зависимостей)
        └── ui.js
             ├── budget.js   (CATEGORIES, findCategory)
             └── format.js   (formatMoney, formatSigned, formatDate, formatPercent)
```

Циклических зависимостей нет: логика (`budget.js`, `format.js`, `storage.js`) ничего не знает об
интерфейсе, а `ui.js` ничего не знает о хранении и расчётах.

## Творческое задание

Добавлен независимый модуль `storage.js` (сохранение операций, лимита и темы в `localStorage`).
Разделение повышает сопровождаемость: расчёты можно тестировать без браузера (`tests/test.mjs`),
внешний вид меняется только в `ui.js`/CSS, а способ хранения (например, замена на сервер)
меняется только в `storage.js`, не затрагивая остальной код.

## Ответы на контрольные вопросы (кратко)

- **Модуль** — файл со своей областью видимости; доступно другим только то, что экспортировано.
- **Отличие от обычных скриптов:** свой scope, строгий режим, `import/export`, загрузка с учётом зависимостей, выполняется один раз.
- **`type="module"`** включает режим ES-модулей для скрипта.
- **Named export** — `export function f(){}`, импорт `import { f } from "./x.js"`; **default** — один на модуль, импорт без фигурных скобок.
- **Путь важен**, т.к. браузер загружает файл по URL; нужны `./` и расширение `.js`.
- **HTTP-сервер** нужен, потому что при `file://` браузер блокирует загрузку модулей (CORS).
- **Циклическая зависимость** — A импортирует B, а B импортирует A; приводит к неопределённым значениям.
